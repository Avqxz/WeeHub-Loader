A few useful details

Before you jump in.

Do I need a key?

Yes. The loader opens a key screen. A valid key is checked before WeeHub downloads. This website does not generate or sell keys.

Will my old loader still work?

Yes. The existing /loader address remains available. The new /loader.lua address opens the same current key screen.

Does every activity work in every game?

No. This build targets Bubble Gum Simulator INFINITY. Some features have partial support and live-game behavior is not fully verified. Check activity status and keep new automations off until you have selected their settings.

What is saved between sessions?

Per-game selections and limits can be saved when your environment supports local files. New automation toggles begin disabled. The key screen can prefill the last key you entered; it still validates that key when you unlock.

Where do I get the raw loader?

Open loader.lua for the public key-screen script. Your private base script continues to require key validation.
